# Manage AGENTS.md

本技能用于对项目根目录的 `AGENTS.md` 文件进行**全生命周期管理**（从零创建、日常增量更新、定期审查与防腐烂瘦身）。

---

## 核心认知：为什么它需要长期管理？

在绝大多数 Agent 运行框架（Harness）中，根目录的 `AGENTS.md` 会在**每一轮对话开启时都被默认、全量加载进上下文**。
- **每一轮对话都在为它付费，也在消耗模型的注意力**。
- **它最容易“悄悄变胖”并发生腐烂**：多人或多 Agent 协作后，经常有人把冗长的 API 文档、临时修 Bug 的代码片段、零碎的格式要求塞进这里，导致上下文急剧膨胀，Agent 抓不住重点。
- **定位铁律**：**它是“总机调度室与指路牌”，绝不能变成“百科全书”**。全篇建议始终控制在 **50~100 行内**。

---

## 三大核心管理场景

根据用户的意图，进入对应的操作模式：

### 场景一：从零创建（Initialize）
当项目刚建立或尚未有 `AGENTS.md` 时触发：
1. **探查现状**：检查项目主要代码、配置与框架，提炼出 1~2 句话的项目定调。
2. **理清验证闭环**：
   - 提取项目专属的**测试命令**（特别是跑单测的针对性命令）；
   - 提取**本地服务启动方式**，并确认 Agent 能否作为使用者发起调用（如 healthcheck 接口、`curl` 样例）并读取日志。
3. **设置指路牌**：明确指引 Agent 渐进式索取信息：
   - 需求与方案 👉 查阅 `.agents/specs/`
   - 代码风格与规矩 👉 查阅 `.agents/rules/`
   - 专属技能与工作流 👉 查阅 `.agents/skills/`
4. **制定 2~3 条绝对物理红线**：只列破坏性高压电线（如禁止强推分支、禁止未确认删除数据），不把日常规范当死线，为后续排查留出“逃逸窗口”。
5. **坚决剔除的冗余（反模式）**：
   - ❌ 不写基础命令科普（如 `npm install`、`git clone` 等常识）；
   - ❌ 不写长篇 API 接口文档（放进 `.agents/specs/`）；
   - ❌ 不写琐碎的代码格式偏好（放进 `.agents/rules/`）。

---

### 场景二：增量更新（Update）
当项目的测试工具变更、本地启动方式调整、或踩了重大新坑需要追加铁律时触发：
1. **定点修改**：只针对性修改对应的章节，严禁推倒全篇重写。
2. **保持特异性**：不要写通用常识（例如不教模型如何执行 `npm install`），只记录本项目特殊的运行方式。
3. **及时清理废弃规则**：如果某个历史红线已经通过工程化手段修复（例如加了自动化 CI 拦截），及时将过时的口头红线移除。

---

### 场景三：审查与瘦身（Review & Prune）
当 `AGENTS.md` 篇幅过长（超过 100 行）、或者发现 Agent 注意力经常被入口信息干扰时触发：
1. **行数审查**：全文是否超过 100 行？如果超过，立刻启动修剪。
2. **清理百科全书式内容**：
   - 发现大段具体 API 参数或表结构？👉 移至 `.agents/specs/`。
   - 发现细枝末节的语法风格或缩进建议？👉 移至 `.agents/rules/` 或交给 linter 配置文件。
   - 发现通用的编程科普？👉 直接删除。
3. **恢复指针本色**：确保 `AGENTS.md` 门面始终保持骨架清晰、纯净精悍。

---

## 标准文件模板参考

```markdown
# AGENTS.md

## 1. 项目定调
本项目是 [一句话说明项目核心业务与技术栈，如：基于 Go 的退款中台微服务，对外提供 gRPC 接口]。

## 2. 验证与闭环（Testing & Observability）
- **测试命令**：\`[针对性单测命令，如：go test -v -run TestSpecific ./...]\`
- **本地服务启动**：\`[本地启动命令，如：make dev]\`
- **调用验证**：本地启动后，可通过 \`curl http://localhost:8080/health\` 验证服务健康状态。
- **可观测日志**：运行日志输出在 \`logs/app.log\`，排查报错时请直接查看该文件。

## 3. 上下文指引（Context Routing）
深入了解本项目资产，请按需查阅对应抽屉（需要时再读，不要提前全量加载）：
- 业务需求与技术方案：查阅 \`.agents/specs/\`
- 项目规则与约束：查阅 \`.agents/rules/\`
- 项目专属操作技能：查阅 \`.agents/skills/\`

## 4. 绝对高压红线
1. 严禁在代码中硬编码任何账号密码、私钥或 API Token。
2. 严禁未经用户明确授权执行任何破坏性的数据库清除脚本。
```
